# Цитоскоп — демо админки

Статическая демо-версия админки врача для просмотра цифрового цитологического препарата с разметкой ИИ.

- Снимок обезличен: без этикетки, штрихкода и номера.
- Разметка — предварительная оценка программы, не диагноз.
- Отметки (подтвердить / отклонить / сменить класс / своя рамка) сохраняются только в вашем браузере.
